# Текущий формат Excel-расписания

Файл: `schedule.xls`

Проверенный актуальный пример: расписание занятий с 01.09.2026 по 04.09.2026.

## Структура листа

- Используется первый лист: `Лист1`.
- Заголовок периода находится в строке с текстом `РАСПИСАНИЕ ЗАНЯТИЙ с ... по ...`.
- Рабочая строка заголовков начинается с ячейки `ДНИ НЕДЕЛИ`.
- Группы расположены широкой матрицей: для каждой группы используется пара колонок.
- Первая колонка пары содержит дисциплину, вторая колонка пары содержит кабинет.
- Дни недели находятся в первой колонке, номера уроков - во второй.
- В файле много объединенных ячеек, поэтому парсер должен читать значения из матрицы, а не ожидать плоскую таблицу.

## Паттерны занятий

- Обычная запись: `Математика Мещерякова О.Н.` + кабинет `302`.
- Спортзал записывается в колонке кабинета как `с/зал`; это не разделитель подгрупп.
- Несколько занятий в одной ячейке могут быть записаны через `/`.
- Для языков встречается паттерн `Англ яз/Нем Буровина М.В./Журавлева Н.С.` + кабинеты `224/224(а)`.
- Аналогичный паттерн: `Нем яз/Информатика Журавлева Н.С./Ширстова А.Д.` + кабинеты `224а/407`.
- Некоторые занятия могут быть без преподавателя или кабинета: `ПП`, `УП`.
- Встречаются опечатки и плотные записи без пробела перед инициалами, например `ЛапшинАВ.`.

## Важные правила для будущего API-импорта

- Хранить дисциплину, преподавателя и кабинет раздельно, даже если в Excel они частично смешаны.
- Не делить кабинет по `/`, если это значение `с/зал`.
- Для разделенных занятий сопоставлять предметы, преподавателей и кабинеты по позициям.
- Сохранять исходную строку Excel для диагностики импорта.
- Показывать спорные разборы в режиме предпросмотра, а не молча угадывать.
- Нормализовать названия групп, но не терять исходное написание из Excel.
